# Diamond Shape Classification 💎

## 📌 Overview

This project uses **YOLO, Deep Learning, and Computer Vision** to classify diamond images into different shape categories through an interactive Streamlit web application.

Users can upload a diamond image and view the predicted shape and confidence score.

## ✨ Features

- Diamond shape classification
- Image upload through Streamlit
- Prediction with confidence scores
- Multiple diamond shape categories
- Interactive web interface using `app.py`
- Image processing with Computer Vision

## 💎 Supported Classes

- Round
- Oval
- Princess
- Cushion
- Pear
- Emerald
- Heart
- Marquise

## 🛠️ Technologies Used
